# InceptionShell
A Shell running in a Shell - a learning project

<br>

The goal of this project is to combine all the other projects into a single program.

And, of course, to implement some features typical of a shell.

<br>

**Commands (7):**

`info` - for some information

`help` - for some help (not helpfull right now)

`exit` - to escape from the Inception Shell

`echo word number` - will print `word` as often as you tell it by `echo`

`cont number` - will count to your `number` - if you want to print everything add `-y`

`calc mathproblem` - will slove your `mathproblem` but ignors math rules

`wsky word number -v/-h` - will build a skyscraper with the height `number` using your `word` (`-v` vertical / `-h` horizontal)
